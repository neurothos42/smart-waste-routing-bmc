# Contributing to Smart Waste Routing BMC

Thank you for your interest in improving this project!

## How to Contribute
1. Fork the repository and create a feature branch (`git checkout -b feature/your-feature`).
2. Follow PEP 8 style guidelines for Python code.
3. Add or update unit tests in `tests/` for any routing or API changes.
4. Run `pytest -v` locally to verify all tests pass.
5. Open a Pull Request describing your changes clearly.
